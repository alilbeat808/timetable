## 📂 파일 구성

- `index.html` : 메인 웹 애플리케이션

- `app.js` : 애플리케이션 로직, 공강 교집합 분석 엔진, HML 파서
- `timetable_data.js` : 브라우저 전역 시간표 데이터셋
- `timetable_data.json` : 교사/학반/부서/시간표 JSON 데이터
