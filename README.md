## 📂 파일 구성

- `index.html` : 메인 웹 애플리케이션
- `app.css` : 반응형 스타일시트 (프리텐다드 폰트, 파스텔 과목 배지, 다크모드, 인쇄 스타일)
- `app.js` : 애플리케이션 로직, 학생 시간표 분석/검색 엔진, 공강 교집합 분석 엔진
- `timetable_data.js` : 브라우저 전역 시간표 데이터셋 (교사, 학반, 3학년 전교생)
- `timetable_data.json` : 교사/학반/학생/부서/시간표 JSON 데이터
- `update_students.js` : 3-1.xlsx ~ 3-7.xlsx 엑셀 파일을 읽어 학생 시간표 데이터를 갱신하는 스크립트
- `update_data.ps1` : HML 파일 및 학생 엑셀 파일 변경 시 원클릭 데이터 갱신 파워쉘 스크립트
